---
title: Quick Start
description: Install the upstream product and run heuristic fixture demos without AWS credentials.
---

Clone the upstream product (not this docs site) and exercise the shared core locally.

**Prerequisite:** Node.js **24+** (matches product `engines` and Lambda runtime).

```bash
git clone https://github.com/jajera/pr-readiness-coach.git
cd pr-readiness-coach
npm install
npm run build
npm test
```

## Fixture demo (no Bedrock)

```bash
chmod +x fixtures/demo.sh
./fixtures/demo.sh
```

Or run the CLI directly:

```bash
npm run pr-ready -- --local --path fixtures/demo-app/not-ready
npm run pr-ready -- --local --path fixtures/demo-app/ready
```

Expected:

| Path | Verdict | Exit |
|------|---------|------|
| `fixtures/demo-app/not-ready` | **NOT READY** | `1` |
| `fixtures/demo-app/ready` | **READY** | `0` |

All fixture secrets are placeholders only.

:::tip
`--local` is heuristic-only. Full Bedrock mode needs `AWS_REGION` (or `AWS_DEFAULT_REGION`) and credentials that can call Bedrock in that region.
:::
